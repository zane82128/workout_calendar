## 已確認規則與驗收

### 重量紀錄改版：已實作，尚未發布

狀態：2026-10-20 使用者完成規則及草圖確認後授權實作，本地已接上正式資料；實際檢查與限制見 [本次驗收](../validation/2026-10-20-weight-records.md)。不代表其他未來想法已獲授權或線上用戶已取得新版。

已確認流程為「選動作 → 帶入上次重量 → 調整 → 完成」。保留舊資料且不納入新比較；新紀錄只代表實際完成，不以新增空白卡片代表完成。

第一輪已確認（2026-10-20，使用者逐項選擇）：

| 問題 | 已確認規則 | 影響 |
| --- | --- | --- |
| 同日同動作重複完成 | 每天每動作一筆，保留當天最高重量 | 同日再次完成較低或相同重量，不新增第二筆或降低當天最高；更正錯誤數字與再次完成是不同操作 |
| 修改／刪除後的比較 | 依剩下的有效紀錄重新計算上次及最高 | 不保留已刪除／更正的錯誤最高值；同一天沒有存下的較低重量不會被自動還原 |
| 本次精簡範圍 | 保留日曆、動作管理、重量紀錄／比較及休息倒數；收起訓練總計時、共用備忘錄及容量圖表 | 收起功能入口，不刪除既有資料；更新與離線能力持續保留 |

第二、三輪已確認：

- 新紀錄只輸入 kg，允許非負小數；徒手填 0 kg，代表沒有外加重量，不是體重。空白、負值及無效數字不能完成。沒有上次時欄位保持空白，不自動把未填當成 0。
- 可記今天或補登過去，不能記未來；日期依使用者裝置的本地日期判斷。「上次」是所選日期之前最近一次新版完成紀錄，排除當天，不按補登先後排序。
- 同日已有紀錄時另外顯示「當天最高」，不將它混成上次。歷史最高則來自目前全部有效新版完成紀錄；補登舊日期也會看到目前已達到的歷史最高，舊版資料及已刪紀錄不納入。
- 日曆選日期可查閱歷史、更正或刪除新版紀錄；舊版標示「舊版紀錄」且只供查閱，保留原 kg／lb、次數、組數與備註，不自動轉成已完成。新版不提供單筆備註、Copy 或直接搬動日期；日期填錯可刪除後重新補登。
- 動作「刪除」改為「封存」：從新增選單隱藏但歷史保留，可恢復後繼續使用同一動作的比較資料。改名只更新清單及之後新建的紀錄，已存歷史名稱不改寫；更正重量不順便覆寫歷史名稱。
- 日曆灰色表示當天只有舊版紀錄，橘色表示有新版已完成；同日兩者並存時橘色優先，詳情仍分開列出。沒有任何紀錄時維持一般日期外觀，不能只靠顏色區分，須有圖例／文字說明。

#### 可操作的主要驗收路線

使用隔離資料：先準備一筆舊版 lb 紀錄及 note，另建立測試動作。依序在過去不同日期完成 40、45、42.5 kg，按上表切換日期確認上次／當天／最高；同日再完成較低值、再用更正操作降低錯填值，驗證兩者不同。依序測試封存、恢復、改名、刪除、重整與離線重開，核對舊資料原值及新比較。任何測試不得清除正式用戶資料。

本次沒有新增永久刪除動作、備份匯出／匯入、帳號同步、Program、容量分析或 UI 風格重設。新版紀錄刪除的防誤觸介面及版面安排可在實作前以草圖說明，不能自行加入自動清除資料政策。

驗證方式：資料規則的 Node 測試、隔離瀏覽器的產品操作、既有升級目的適配新版，以及原始舊版與四頁版實際來源升級到本版。測試結果與人工查看範圍集中於本次驗收紀錄，不把自動化通過當成所有手機情境已驗證。
