# 產品規格與驗收

## 單筆重量 kg／lb（2026-10-22，本地實作）

使用者確認在本次重量旁選 kg 或 lb，切換保留輸入數字、不自動換算該欄；例如 20 + lb 記為 20 lb。上次、歷史最高及當天最高依本次所選單位換算，完成清單保留最高那筆輸入使用的單位，更正也可選單位。較低重量重複完成不取代當天最高或其單位。舊新版 kg 記錄仍為 kg，舊版只讀 lb 原值不變、不納入新比較。

內部按 kg 精度比較，畫面一般顯示最多兩位小數；非常小的非零值不顯示成 0。未修改的預填／更正沿用原精度，不因四捨五入後再存產生漂移。切換單位不寫成績，但視為未送出的選擇；本頁切日期／動作維持所選單位，普通重開預設 kg，套用更新則保留本頁單位與輸入。見 [驗收](../validation/2026-10-22-weight-units.md)。

2026-10-22 回報文案：依使用者要求移除表單「版本…關閉分頁可能遺失」整句提示。版本仍隨回報送出，分頁草稿保存方式不變；僅移除顯示及其 DOM 寫入。

## 分類收納介面（2026-10-22，本地實作）

使用者要求紀錄、管理與組合選擇都減少長清單，並同意分類收合方案：

- 紀錄頁只顯示目前動作與「選擇動作」。開啟像素風原生 dialog 面板，依部位分類並顯示數量，預設展開目前動作所屬分類，可同時展開多區。點動作後關閉面板，才切換重量比較與預填；搜尋與取消不改原選擇或輸入。搜尋直接列出符合名稱／分類的結果；搜尋無結果有提示。支援關閉按鈕、Escape 及原生 dialog 焦點管理。
- 動作管理預設分類全部收合，每區只列名稱、不重複類別。每列「⋯」展開改名／封存；封存區內仍按分類查看及恢復。新增表單收到「＋新增動作」裡。
- 組合的選擇動作也依分類收合，多選跨區保留，分類標題顯示已選數量；原本勾選順序、上移與移除規則不變。組合編輯時已選但封存的動作仍在順序清單供移除。
- 類別順序、類內筆畫、訓練／待做／完成／回報規則不變。分類展開狀態在本次操作重新呈現時保留，普通重開不承諾保留；升級快照保留有 ID 的展開狀態與原編輯草稿。見 [本輪驗收](../validation/2026-10-22-exercise-groups.md)。

## 已確認規則與驗收

### 重量紀錄改版：已實作，尚未發布

狀態：2026-10-20 使用者完成規則及草圖確認後授權實作，本地已接上正式資料；實際檢查與限制見 [本次驗收](../validation/2026-10-20-weight-records.md)。不代表其他未來想法已獲授權或線上用戶已取得新版。

已確認流程為「選動作 → 帶入上次重量 → 調整 → 完成」。保留舊資料且不納入新比較；新紀錄只代表實際完成，不以新增空白卡片代表完成。

第一輪已確認（2026-10-20，使用者逐項選擇）：

| 問題 | 已確認規則 | 影響 |
| --- | --- | --- |
| 同日同動作重複完成 | 每天每動作一筆，保留當天最高重量 | 同日再次完成較低或相同重量，不新增第二筆或降低當天最高；更正錯誤數字與再次完成是不同操作 |
| 修改／刪除後的比較 | 依剩下的有效紀錄重新計算上次及最高 | 不保留已刪除／更正的錯誤最高值；同一天沒有存下的較低重量不會被自動還原 |
| 本次精簡範圍 | 保留日曆、動作管理、重量紀錄／比較及休息倒數；收起訓練總計時、共用備忘錄及容量圖表 | 收起功能入口，不刪除既有資料；更新與離線能力持續保留 |

第二、三輪已確認：

- 新紀錄只輸入 kg，允許非負小數；徒手填 0 kg，代表沒有外加重量，不是體重。空白、負值及無效數字不能完成。沒有上次時欄位保持空白，不自動把未填當成 0。
- 可記今天或補登過去，不能記未來；日期依使用者裝置的本地日期判斷。「上次」是所選日期之前最近一次新版完成紀錄，排除當天，不按補登先後排序。
- 同日已有紀錄時另外顯示「當天最高」，不將它混成上次。歷史最高則來自目前全部有效新版完成紀錄；補登舊日期也會看到目前已達到的歷史最高，舊版資料及已刪紀錄不納入。
- 日曆選日期可查閱歷史、更正或刪除新版紀錄；舊版標示「舊版紀錄」且只供查閱，保留原 kg／lb、次數、組數與備註，不自動轉成已完成。新版不提供單筆備註、Copy 或直接搬動日期；日期填錯可刪除後重新補登。
- 動作「刪除」改為「封存」：從新增選單隱藏但歷史保留，可恢復後繼續使用同一動作的比較資料。改名只更新清單及之後新建的紀錄，已存歷史名稱不改寫；更正重量不順便覆寫歷史名稱。
- 日曆灰色表示當天只有舊版紀錄，橘色表示有新版已完成；同日兩者並存時橘色優先，詳情仍分開列出。沒有任何紀錄時維持一般日期外觀，不能只靠顏色區分，須有圖例／文字說明。
