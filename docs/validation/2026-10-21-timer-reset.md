# 休息倒數重置

候選版 2026.10.21.2；本地修改，未提交、推送或部署。

實際執行 npm run release -- --release 2026.10.21.2：建置、產物檢查、11 項資料測試、9 組產品情境（含新增重置案例）與 12 組更新情境全部通過；git diff --check 通過。

隔離產品測試新增：設定 5 秒，暫停至剩 3 秒後重置為 5 秒；運行中重置後等 6 秒仍為 5 秒；重整保留；重啟能倒數；到期後可再次重置。到期提醒音停止沿用 stopAlarm 實作，此瀏覽器情境關閉 AudioContext，未實際驗證喇叭聲或手機背景行為。多分頁各自播放中的提醒音不在本次處理範圍。

手動：npm run preview → 展開休息倒數 → 設 1 分 30 秒 → 開始 → 重置，應顯示 01:30 且不繼續扣秒。分別在暫停與到期鈴聲播放時按重置，再重開確認設定保留。實機音訊仍待驗收。
