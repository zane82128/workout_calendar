# 分類排序、訓練組合與休息變色驗收

本地候選 2026.10.21.4；本輪包含先前尚未推送的回報介面，未提交／推送／部署。本紀錄區分自動化與手機實機，不當作正式站已更新。

## 可操作的驗收

1. 執行 npm run preview，開啟 http://127.0.0.1:5173/workout_calendar/src/ 。如本地 PWA 還是舊版，從版本與更新檢查並套用，不清除資料。
2. 查看動作選單：類別在前，同類相鄰；在動作管理與組合選擇器核對相同排序。筆畫排序明確指定繁中，不跟電腦預設語系走。
3. 動作管理 → 訓練組合 → 輸入「推日 TEST」，展開選擇動作，勾兩個並上移調整 → 儲存。重複名稱、空選擇應拒絕且不改原資料。
4. 記錄 → 加入訓練組合 → 選組合 → 加入今天。即使目前查閱過去日期，也回今天；只看到兩個待做，不產生完成或日曆橘色。再次加入仍兩筆。
5. 點待做的記錄 → 輸入 40 → 完成；該動作移至已完成，歷史比較遵守原規則。刪除該成績會再顯示原待做；移除待做本身不刪已存成績。
6. 編輯／刪除組合，今天清單與成績不變。封存一個動作後匯入會略過並提示；原先已入清單的封存動作不能直接記錄。重開、離線查閱，組合與清單應保留。
7. 設休息 2 秒，開始並收合；到期入口變橘、顯示休息結束，十秒後恢復。再測到期後按開始或重置，立即恢復原色。淺深色都應可讀。
8. 回報入口沿用上一份表單驗收；只送 TEST 文字，不附訓練資料。
