# RPG 雙主題驗收

2026-10-20；本地候選版 2026.10.20.3，未提交、推送或部署。

## 手動查看

1. 專案目錄執行 `npm run preview`，開啟 http://127.0.0.1:5173/workout_calendar/src/ 。若已有預覽程序，直接使用；本地舊版可能需要「版本與更新 → 檢查更新」後套用。不要清除網站資料。
2. 頁首「外觀」選冒險日誌，確認米色紙張、綠色按鈕與像素文字；選深色地城，確認深色面板、金色按鈕與火把。
3. 重整後應保留手動選擇。選跟隨系統，再調整裝置深淺色，App 應同步。
4. 切至動作管理、展開日曆與休息倒數，檢查文字與按鈕可讀；完成測試重量，底部提示仍一秒消失。
5. 首次完整載入後離線重開，確認介面與字型可用。請用本地測試資料，不刪正式紀錄。

## 實際檢查與限制

`npm run release -- --release 2026.10.20.3` 完整通過：建置與產物檢查、11 項資料規則、9 組產品情境、12 組更新情境；`git diff --check` 通過。結果位於 .release-tests/product-results.json 與 results.json（產生檔不提交）。

隔離 Chromium：新增主題測試涵蓋系統變更、手動偏好跨重整、離線字型與主題、切換不改訓練資料，以及 320／390／768 寬度無水平溢出。人工查看 theme-light.png 與 theme-dark.png（.release-tests/）的 390 寬全頁截圖，兩款可讀。產品通知的無版面推動檢查改用文件座標，避免較長頁面自動捲動被誤判為元素位移；等待字型載入後檢查。

手機實機、瀏覽器縮放、系統大字與不同裝置的像素銳利度尚未驗收。原生日期／選單彈出介面由作業系統決定。字型缺字會 fallback，第一次載入可能短暫出現系統字型。精細石牆、植物及沙漏場景插畫未重製；本版是簡化的可操作主題。
