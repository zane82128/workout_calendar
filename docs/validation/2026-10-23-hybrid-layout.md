## 親自驗收

1. 執行 `npm run preview`，開啟列出的網址。設定切深／淺色，確認金框主卡、次要卡片和像素圖示都清楚。
2. 點「選擇動作」，確認分類小字、名稱大字，上次與最高可辨識，沒有「當天最高」重複欄位。
3. 完成 20 kg，再完成 25 kg、15 kg；完成清單應只保留 25 kg，重新整理仍在。更正與刪除應正常。
4. 選有氧，確認分鐘／下仍可切換並獨立比較。
5. 展開休息設定短倒數，收合後確認時間仍跳動，結束橘色提示維持十秒；重置仍回設定值。
6. 開啟加入訓練組合、管理頁、日曆與設定，確認入口都可操作；向下滑動，紀錄／動作管理仍吸附頂部。

## 限制

實際使用原有 Fusion Pixel 繁中字體及手寫 SVG 像素圖示，非生成草圖的逐像素複製。未新增遠端字型、資料欄位或服務。Android／iOS 鍵盤、觸控、原生日曆與 PWA 實機仍待驗收；展開日曆或文字放大後，完成按鈕可能需要捲動。
