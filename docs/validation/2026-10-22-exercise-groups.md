# 分類收納介面驗收

本地候選 2026.10.22.1，未 commit／push／部署。

## 操作驗收

1. npm run preview → http://127.0.0.1:5173/workout_calendar/src/ ，如看到舊介面，從版本與更新檢查並套用本地候選，不清網站資料。
2. 紀錄 → 選擇動作：目前部位展開、其他分類可獨立展開，點名稱後關閉並更新比較。在重量欄先填數字，打開搜尋再關閉，數字與選擇應維持；搜不到應提示，Escape／關閉按鈕可離開。
3. 動作管理：分類與新增表單預設收合；展開胸、背可同時查閱。分類內只有名稱；點 ⋯ 看改名／封存，再點 ⋯ 可收合。新增、改名、封存、恢復仍沿用原資料規則。
4. 訓練組合 → 選擇動作：展開胸勾一項、收合後到背再勾一項，回胸仍勾選，標題顯示已選數量，儲存保持勾選順序。編輯後可上移／移除。
5. 測淺／深色及 Android 鍵盤、返回鍵、長名稱；目前桌面模擬不等同 Android 實機驗收。
