## 親自驗收

1. npm run preview → http://127.0.0.1:5173/workout_calendar/src/ ，必要時從版本與更新套用本地候選，不清網站資料。
2. 頁面下方展開「回報問題」，輸入主旨、內容；不送出先重整，文字應保留。
3. 斷網點送出，應說明離線而不清空；連線後手動重試。
4. 正常送出後應顯示已送出與編號，欄位清空；在私人表格核對相同編號的一列。請用標示 TEST 的文字，避免當成真實問題。
5. Android 另確認長內容、鍵盤、離線及兩種主題；尚未完成實機驗收。

## 限制

沒有截圖、聯絡方式、回覆或處理進度；不自動上傳訓練紀錄。草稿只在本分頁 sessionStorage，不保證關閉／解除安裝後保留，也不跨裝置同步。公開入口僅有原型的每日／總量限制，沒有完整防灌水；Google 或網路失敗時可能其實已保存，須相同內容重試以去重。若編輯內容後再送，會是新回報。免費帳號實際用量仍需擁有者留意。
