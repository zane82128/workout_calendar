## 可操作驗收

1. npm run preview，開 http://127.0.0.1:5173/workout_calendar/src/ ，舊本地版可從設定內版本與更新檢查套用；不要清網站資料。
2. 展開紀錄頁日曆／休息，往下捲。標題消失、紀錄與動作管理分頁仍停頂部，不透明底色讓內容不混在一起。
3. 在紀錄頁捲到中段 → 切動作管理 → 展開分類並往下捲 → 切回紀錄，應還原原位置；再回管理亦然。內容收合造成高度改變時，位置可能被限制至頁尾。
4. 回頁首點設定。切淺深色、展開版本與更新、填回報草稿。關閉再開，文字保留；設定外的背景不可操作。關閉／Escape 應回原頁，不切換主分頁。
5. 當有新版準備好，吸附導航下出現查看入口，點後開設定，可選立即更新或稍後。下載完成不應自行彈出設定。原更新與草稿保留規則維持。
6. Android 實機另確認頂部安全區、鍵盤、返回鍵及原生選單；此輪桌面模擬不是實機通過。

## 實際結果

建置與產物檢查及 26 項單元通過；適配入口後 test:product 的 15 組與 test:update 的 12 組均通過，共 53 項／組。新增產品情境實測 390×600：導航在捲動後 y≈0、標題離開視窗、紀錄與管理各自位置精確還原、設定內主題切換、關閉／Escape、回報草稿保留。升級情境驗證就緒的外部快捷入口可開設定，設定內稍後／套用及原資料／草稿保留；首次安裝離線、節流、失敗與多分頁仍通過。

light/dark × 320／390／768 的設定面板無水平溢出。人工查看 .release-tests/settings-dark.png 與 sticky-tabs-dark.png，控制項可見、分頁吸附底色正常。npm run ui:maps 通過，git diff --check 通過。沒有真實 Google 回報送出，也沒有更動正式訓練資料。

限制：頁面位置不是永久設定，普通關閉重開不承諾還原；高度變化會限制實際位置。設定長內容需在面板內捲動；手機背景／鍵盤／安全區及螢幕閱讀器實機未驗證。
