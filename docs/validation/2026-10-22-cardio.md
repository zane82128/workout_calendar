## 手動操作

1. `npm run preview`，開啟終端機列出的網址，選有氧動作（例如跳繩）。
2. 輸入 10.5 分鐘並完成，再選「下」輸入 500 並完成。當天清單應同時有兩筆。
3. 再記 5 分鐘，當天分鐘應仍是 10.5；選「下」的最高應仍是 500。
4. 次數輸入 2.5、0 或空白，應顯示錯誤且不新增紀錄。分鐘可記小數但不能為零。
5. 更正分鐘為 3，分鐘最高應重新計算；刪除分鐘不影響次數。補登過去日期後，上次只查所選日期之前的同單位紀錄。
6. 重整確認資料仍在，再選重量動作，應恢復 kg／lb 與原重量比較。

限制：有氧更正只改數字；單位填錯時刪除重記。舊重量保持重量，不納入有氧比較。舊 v2 App 保留但不顯示新有氧資料，不應回退會丟棄未知欄位的 v1。備份位於同一瀏覽器本機，清除網站資料仍會遺失，並非雲端備份。
