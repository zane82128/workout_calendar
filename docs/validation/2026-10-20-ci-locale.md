# PR 檢查的語系差異修正

2026-10-20。本地修正，尚未推送及在 GitHub 重新驗證。

GitHub PR #1 的產品測試預期第一筆紀錄名稱為平板臥推，實際為伏地挺身。隔離 Chromium 證實：未指定 locale 的 localeCompare 在 en-US 將伏地挺身排在前、zh-TW 將平板臥推排在前。測試未先選動作，卻假設第一個選項是 bench，因此測到不同動作。

修正 tests/product.test.mjs：各情境開始先以穩定 ID 選擇 bench；預設測試語系 zh-TW，可用 TEST_BROWSER_LOCALE=en-US 覆寫。本次不改 App 排序、功能規格或用戶資料；沒有新增產品決策。

實際結果：en-US 執行 `npm run release -- --release 2099.01.01.1`，建置、產物檢查、11 項單元、9 組產品與 12 組升級全部通過；zh-TW 再執行 test:product，9 組通過。2099 ID 僅是 CI 候選測試編號，不是正式發布日期。

後續驗收：提交並推送同一功能分支，等待 PR 自動檢查變綠；遠端 Ubuntu 結果仍須確認，不能以本地 Windows 通過取代。
