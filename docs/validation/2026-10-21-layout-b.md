# B 版手機版面驗收

本地候選 2026.10.21.1，未提交／推送／部署。

實際執行 `npm run release -- --release 2026.10.21.1`：建置、產物檢查、11 項資料測試、9 組產品情境、12 組更新情境全部通過。

額外隔離 Chromium 檢查：light/dark 各以 320、360、390、430 × 740 預設字級，主要完成按鈕在首屏內且至少 44px 高；切過去日期、展開日曆均無水平溢出。390 × 420 短視窗可捲動輸入並完成；這不等同真實手機鍵盤驗收。人工查看 390 × 780 的深色全頁截圖：頁首同列、日期與日曆同列、空成績小字、重量與完成在首屏。產生截圖位於 .release-tests/layout-b-light.png、layout-b-dark.png（不提交）。

## 親自驗收

1. 專案目錄執行 `npm run preview`，開啟 http://127.0.0.1:5173/workout_calendar/src/ 。舊本地 PWA 如未更新，從版本與更新檢查並套用；不要清除資料。
2. 切換淺／深色，確認頁首與分頁精簡、日期旁能展開日曆，完成按鈕更早出現。
3. 展開篩選與日曆後選日期／動作，確認可收合、無重疊；有成績時數字大、無紀錄時文字小。
4. 用測試動作記重量、更正、刪除；確認當天最高仍在比較區，完成通知一秒消失。查閱動作管理、休息及更新入口。
5. Android 實機另看鍵盤彈出後的完成操作、系統大字、長動作名，以及橫向畫面；目前僅桌面模擬尺寸，不宣稱手機實機已驗收。
